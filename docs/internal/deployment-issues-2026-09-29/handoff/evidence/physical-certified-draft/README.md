Dependencies: reviewed physical-committed-draft patch5b5f577c (fixed opaque cap, capture/finish split) and physical_source_coordinator module (existing APIs compatible through edc2b97b). This draft changes only external copies. Rustfmt parsed; no build, service or regression execution performed. Existing main options needs the separate main-raw-compat.patch (`require_committed:false`); this preserves the existing explicitly non-serving CLI. A certified CLI/server must be wired only after complete source admission audit, not by toggling that field alone.

Protocol is mandatory version2, with explicit OpenRequest::CertifiedSnapshot and CertifiedResume and distinct CertifiedManifest/CertifiedResumeInfo response kinds. Raw/committed mismatches fail both source-info validation and client frame-kind acceptance; no fallback/downgrade exists. Authentication still precedes Open and factory invocation. Bounds precede allocation. Client operations retain poison-before-await behavior, including dropped futures. Ordinary raw variants still work only with matching raw requests. Version1 peers fail before payload processing.

`open_committed_primary_session(db, coordinator, history, parent, transfer_limits, request, work, fence_timeout)` is a separate factory. It preserves shared SourceWorkLimiter cancellation/job ownership. Snapshot uses coordinator capture then hashes after the fence has returned. Resume creates no checkpoint. Exact DB pointer/history binding is checked through the opaque capability; source durable history/IDENTITY is checked before and after work. The source retains one opaque barrier for a partially consumed interval and obtains the next cap only once the receiver cursor reaches the old cap. Each returned raw batch ends at or below that certified boundary; source writes after it remain excluded. Certification poison stops new caps while ordinary primary admission remains writable.

`ReceiverOptions::require_committed` chooses only certified opens/reconnects. After PollEnd, the existing FIFO worker Position acknowledgement confirms durable apply; exact history/cursor and full barrier equality are required before the private `VerifiedCommittedCut` is minted. Raw CaughtUp never mints it. The cut binds receiver owner UUID, full PhysicalCursor, and source session UUID. Public getters expose history/sequence/session only. A future worker-owned generation-copy command MUST check matches_position against its owner and current durable cursor immediately before capture; a later physical apply makes the old cut stale. A CommittedCut watch notification is not SQL readiness and can be superseded/coalesced like other progress.

Seven new tests cover certified Snapshot+Resume transfer and mode mismatch, version1 refusal before auth/factory, source fixed-cap prefixes under later writes, raw/coordinator mismatch/poison, receiver cut eligibility, actual private TCP snapshot->physical continuation->Resume/Follow, and raw source refusal before receiver directory creation. Existing tests retain explicit raw mode. Tests remain unrun.

Limits: certification proves only the one coordinator's complete semantic admission contract; source raw DB/background/HTTP/Branch/transaction/error paths must all be audited/wired before exposure. Authenticated source claims are trusted; the token is not a remote TLS substitute. No WAL retention lease, SQL serving factory, session migration, immutable generation copy, tenant/auth replication, or PG readiness is added. Default raw CLI cannot claim issue7 completed.
