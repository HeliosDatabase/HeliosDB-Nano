# A11 - ON CONFLICT excluded column references

## Verdict

REAL BUG, fixed.

The checklist's narrow `SET col = excluded.col` surface was already fixed on final main `da4c591`, including the parameterized path. Claude's reg-test-only result was correct for that surface.

The broader A11 compare point exposed a real gap: `ON CONFLICT DO UPDATE ... WHERE excluded.col ...` parsed successfully but the planner dropped the `DO UPDATE` predicate entirely, so conflict updates ran unconditionally.

Implementation:

- Extended `OnConflictAction::DoUpdate` with `selection: Option<LogicalExpr>`.

- Evaluated the predicate before applying assignments in both conflict-update execution paths.

- Preserved MySQL `ON DUPLICATE KEY UPDATE` behavior with `selection: None`.
