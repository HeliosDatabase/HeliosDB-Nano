# Configuration keys, for tests/feature_truth_config.rs.
#
# One key per line: `section.key | owning package | note`.
#
# [known_inert]      nothing acts on the key and the loader does not warn about it
#                    (keys the loader does warn about are INERT_KEYS in src/config.rs).
#                    The owner wires the key or moves it to INERT_KEYS, and removes the line.
# [no_test_sets_it]  the source reads the key, and no test sets it: nothing shows that
#                    changing it changes anything. The owner removes the line together
#                    with the test that sets the key and checks the effect.
#
# The test fails when a key exists that is in neither list, not in INERT_KEYS and not set
# by a test; when a key's name appears nowhere in src/ outside src/config.rs and it is not
# listed as inert; when a listed key no longer exists; and when a [no_test_sets_it] key
# gains a test.
