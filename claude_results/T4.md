# T4 Result — CREATE BRANCH ... AS OF NOW records the branch name (CONFIRMED already-fixed)

## Verdict

**Already fixed — confirmed by both agents.** No source change; regression tests
only.

The checklist claims `CREATE BRANCH b AS OF NOW` leaves an empty branch name in
`SHOW BRANCHES`. On the consolidated baseline (`final/main` `4546be5`) it does
not reproduce — the name is recorded across every AS OF form.

## Adjacent finding — OUT of scope, NEW bug (flagged, not fixed here)

Codex found that `CREATE BRANCH IF NOT EXISTS <name> AS OF NOW` "succeeds" but
`parse_create_branch_sql` appears to treat **`IF`** as the branch name (the
`IF NOT EXISTS` clause is not modeled in `LogicalPlan::CreateBranch`). This is a
real parser bug but is **not** part of T4's acceptance and not in the v3.34
checklist — recommend a separate future item. Not pinned by a test here to avoid
asserting/locking the bad behavior.

## Not a bug

`CREATE BRANCH x FROM main` *without* an AS OF clause returns "CREATE BRANCH
requires AS OF clause" — a deliberate validation.
