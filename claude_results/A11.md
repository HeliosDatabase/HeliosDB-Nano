# A11 Result — ON CONFLICT DO UPDATE excluded refs (CORRECTED)

## Verdict

**REAL BUG — fixed** (Codex `fe030ec`), but NOT the narrow `SET excluded.col`
path. (Corrects my "already-fixed" verdict, which was right for `SET
excluded.col` but wrong for the conditional `DO UPDATE ... WHERE` case.)

## What happened (a good cross-agent catch in both directions)

My A11 pass confirmed `SET col = excluded.col` works on simple + parameterized +
expression + multi-col — and it does. But I **flagged** `DO UPDATE ... WHERE
excluded.col` as a probe spot and did **not** test it myself. Codex tested
exactly that against my own `v334_a11_on_conflict_excluded.rs` and found 2/5 green,
**3 RED**:
- `DO UPDATE SET ... WHERE excluded.qty > qty` with a false predicate returned
  `affected=1` (updated) instead of 0,
- `execute_params_returning` with a false predicate returned `affected=1` and a row,
- a 200-row param-upsert stress applied 200 updates instead of the 100 the
  predicate approved.

I independently reproduced on `da4c591`:
`... ON CONFLICT (id) DO UPDATE SET val = excluded.val WHERE excluded.val > t.val`
with a false predicate gave `affected=1, val=50` (should be `affected=0, val=100`).

## Root cause

The planner **dropped the `DO UPDATE` `WHERE` predicate entirely**, so conflict
updates always ran unconditionally.

## Fix (Codex `fe030ec`)

- `OnConflictAction::DoUpdate` gains `selection: Option<LogicalExpr>`
  (`src/sql/logical_plan.rs`).
- Planner converts `do_update.selection` (`src/sql/planner.rs`).
- Both conflict-update executors (`src/lib.rs`) evaluate the predicate (reusing
  `resolve_excluded_refs`, so it can mix existing-row columns and `excluded.<col>`)
  **before** applying assignments; `false`/`NULL` → skip update (affected 0, no
  RETURNING row). MySQL `ON DUPLICATE KEY UPDATE` preserved via `selection: None`.

## Tests (`tests/v334_a11_on_conflict_excluded.rs`, Codex superset)

My original 2 (SET excluded.col simple + param) plus the WHERE-predicate cases
(false predicate skips; execute_params_returning respects it; 200-row stress with
half predicate-approved). 5/5 after fix.
